Import Cow Records

Required columns: EarTagRFID, VisualID, Breed, Status. Optional: CowName, AgeYears, WeightKg, PhotoURL, Delete. Use Delete=TRUE to remove a cow and its logs.

Import Station List

Required columns: StationID, Label.

Import Feed Types

Required column: Name.

Import Feed Inventory

Required columns: FeedType, AvailableKg. Optional: LastUpdated, Note.

Import Feed Sessions

Required columns: EarTagRFID, Timestamp, GreenFodderKg, ConcentrateFeedKg. Valid rows commit atomically; failed rows move to Data Verification.

Update Live Station From JSON

Accepts clean JSON or tracker text containing a JSON payload. Uses WeightKg="Milking" as live status; numeric WeightKg finalizes a milk log when the cow VisualID exists. Feed values in JSON are ignored.
